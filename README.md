# AMML Ranking Competition 2026

Модель ранжирует русскоязычные фрагменты для каждого поискового запроса. Чем выше скор, тем выше позиция в выдаче. В Train релевантный фрагмент имеет метку `1`, нерелевантный — `0`.

Финальная модель — **E36_gated**. Её обучили и запустили на исходных `train.csv` и `test.csv` в Google Colab (Linux, NVIDIA Tesla T4). Результат Kaggle Public по NDCG@10 составил 0.955127. Это на 0.000614 выше E30. На исходном разбиении E36_gated получила 0.960180 против 0.959469 у E30. Результат Private ещё неизвестен.

## Данные и валидация

| Набор | Пар запрос–фрагмент | Уникальных запросов |
|---|---:|---:|
| Train | 31 530 | 3 042 |
| Test | 13 507 | 1 305 |

- Для предсказаний используются текст запроса, заголовок и текст фрагмента, метаданные статьи и групповые признаки кандидатов. Медиана в Train и Test составляет 10 кандидатов и 7 статей на запрос. После очистки около 2,8% фрагментов длиннее 1 800 символов.
- Раскодируем HTML-сущности, удаляем теги, нормализуем Unicode и пробелы. Пустые заголовки отмечаем отдельным признаком. Пропуски и отрицательные значения в числовых метаданных заменяем на `−1` и отмечаем индикаторами.
- Метрика — средний NDCG@10 по запросам. Кандидаты сортируются по убыванию `prediction`, при равенстве — по возрастанию строкового `id`. При бинарной `relevance` вклад на позиции `r` равен `relevance / log2(r + 1)`. Для нормировки используется идеальный DCG@10 по всем исходным кандидатам запроса. Если IDCG равен нулю, вклад запроса равен нулю.

## Финальная модель E36_gated

1. Замороженный `jinaai/jina-reranker-v3.5` оценивает полный список фрагментов каждого запроса по возрастанию и убыванию строкового `id`. Вход кандидата содержит заголовок и первые 1 800 символов очищенного фрагмента.
2. Исходная ветка E30 обучает LightGBM LambdaMART на прямых скорах Jina, лексических совпадениях, числах, длинах и метаданных. LightGBM XE-NDCG получает те же признаки и восемь статистик для фрагментов одной статьи внутри запроса. Для прямого прохода это среднее, максимум, ранг, отставание от максимума и среднее остальных. Для обратного — максимум, ранг и отставание от максимума.
3. Зеркальная ветка обучает ещё одну пару LambdaMART и XE-NDCG. Во всех признаках Jina, включая статистики статьи, роли прямого и обратного проходов меняются местами.
4. Скоры стандартизируются внутри запроса. В каждой ветке скор лидера равен `0.75·z(LambdaMART) + 0.25·z(Jina)`, а скор для последующих мест — `0.375·z(LambdaMART) + 0.375·z(XE-NDCG) + 0.25·z(Jina)`. В этих формулах исходная ветка подмешивает обратную Jina, а зеркальная — прямую.
5. При ровно 10 кандидатах лидер определяется по смеси двух скоров лидера с весами 50/50. На остальных запросах первое место занимает лидер E30. Во всех запросах кандидаты ниже лидера сортируются по смеси 50/50 скоров для последующих мест. При равных скорах кандидаты сортируются по возрастанию строкового `id`.
6. Для отправки все четыре LightGBM обучаются на всём конкурсном Train. В сабмит записывается `prediction = 1 / ранг` для каждого `id`, 13 507 строк в порядке `test.csv`.

У всех ранкеров 300 деревьев, `learning_rate=0.035`, `num_leaves=11`, `min_child_samples=80`, `reg_lambda=20`, `random_state=42`. Использовали замороженную Jina ревизии `d666730b5ddaae829437e38f5f117b456e81d1d2`. Обучение и инференс для воспроизведённого результата выполнены в Google Colab (Linux, NVIDIA Tesla T4).

## Эксперименты

### E01. Лексические признаки и CatBoost

- Обучаемый ранкер объединит несколько слабых лексических и структурных сигналов.
- Сравнили BM25, TF-IDF, CatBoostClassifier и CatBoostRanker с YetiRank. Для CatBoost построили 62 признака. Валидация — `GroupShuffleSplit` по запросам, 609 запросов в отложенной части.
- BM25 — 0.660505, TF-IDF по тексту — 0.641207, по заголовку — 0.584583, CatBoostClassifier — 0.808045, CatBoostRanker — 0.810145. При увеличенном лимите деревьев ранкер достиг 0.811363, Public — 0.786123.
- CatBoostRanker стал первой пробой. Затем в E02 расширили признаки и проверили LightGBM.

### E02. LightGBM LambdaRank и расширение признаков

- Стемминг, раздельный BM25 по полям, даты, числа и ранги внутри запроса помогут различать близкие фрагменты.
- Сравнили CatBoostRanker с 62 признаками и LightGBM LambdaRank с 62 и 123 признаками на трёх повторных разбиениях по запросам с seed 42, 73 и 2026. Дополнительно проверили смеси с CatBoost и со старым LightGBM.
- Средние 0.799591, 0.806786 и 0.812812 соответственно. LightGBM со 123 признаками получил 0.830460, 0.804019 и 0.803956. На seed 42 смеси достигли максимум 0.829328, CatBoost со 123 признаками — 0.814704 в классификации и 0.812496 в ранжировании.
- Пока оставили LightGBM со 123 признаками. Затем перепроверили результат на новых документах.

### E03. Валидация с исключением общих документов

- Повторяющиеся документы между обучением и валидацией завышают оценку переноса на Test.
- Оставили 457 запросов в holdout. На 2 585 остальных запросах провели пятифолдовую проверку ансамбля из трёх LightGBM по 300 деревьев с исключением общих `document_id`.
- По фолдам 0.800313, 0.800628, 0.821189, 0.799959, 0.796708. Среднее 0.803759, стандартное отклонение 0.009869. Без исключения документов первый фолд давал 0.808398.
- Зафиксировали более строгую схему сравнения. Удаление общих документов одновременно уменьшает размер обучающей выборки.

### E04. Компактный RuBERT Cross-Encoder

- Совместное чтение запроса и фрагмента улучшит оценку смысловой релевантности.
- Дообучили `cointegrated/rubert-tiny2` с классификационной головой на входе запрос, заголовок и текст. Три эпохи, Cross-Entropy, 320 токенов, первый development-фолд.
- NDCG@10 по эпохам 0.687124, 0.678162, 0.659399 при контроле LightGBM 0.800313.
- Вариант уступил табличной модели. Следующим проверили специализированный реранкер.

### E05. Исходная BGE на первом фолде

- Предобученный мультиязычный реранкер даст более сильный сигнал релевантности.
- Замороженная `BAAI/bge-reranker-v2-m3` оценивает пару из запроса и фрагмента с заголовком. Лимит 384 токена, скор — логит модели.
- На первом development-фолде 0.915024 против 0.800313 у E03.
- Прирост достаточно велик для проверки на всех пяти частях development.

### E06. Исходная BGE на пяти фолдах

### E25. Попарный LLM-судья для спорного топ-3
